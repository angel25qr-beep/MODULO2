ETIQUETAS HTML

Aprendiendo a construir páginas web

¿Qué son las etiquetas HTML?

Las etiquetas HTML son instrucciones que sirven para organizar el contenido de una página web. Con ellas podemos escribir títulos, párrafos, insertar imágenes, crear enlaces y organizar información. Cada etiqueta tiene una función diferente y nos ayuda a construir una página web.

Ejemplos de etiquetas

Etiqueta Función
h1 Crear títulos principales.
h2 Crear subtítulos.
p Escribir párrafos.
img Insertar imágenes.
a Crear hipervínculos.
ul Crear listas desordenadas.
table Crear tablas.

Tipos de etiquetas

Las etiquetas se pueden utilizar para diferentes actividades:

  • Texto: permite escribir títulos y párrafos.
  • Imágenes: permite mostrar fotografías y dibujos.
  • Enlaces: permite visitar otras páginas.
  • Listas: permite organizar información.
  • Tablas: permite presentar datos ordenados.
  • Videos y audios: permite agregar contenido multimedia.

Etiquetas semánticas de HTML5

Las etiquetas semánticas sirven para organizar las diferentes partes de una página web. Ayudan a identificar el encabezado, la navegación, el contenido principal y el pie de página.

Etiqueta Función
header Representa el encabezado.
nav Organiza los enlaces de navegación.
main Contiene el contenido principal.
section Agrupa información relacionada.
footer Representa el pie de página.

Importancia de las etiquetas

Las etiquetas son importantes porque permiten crear páginas web organizadas y fáciles de entender. Gracias a ellas podemos combinar textos, imágenes, listas, tablas y enlaces para presentar información de manera clara.
